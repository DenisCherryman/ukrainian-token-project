# Як долучитися до Ukrainian Token Project

Долучатися можна через питання, Pull Request, перевірку відтворюваності та пропозиції легальних корпусів української мови.

Перш ніж надіслати PR:

1. Запустіть `python -m pytest -q`.
2. Якщо змінюєте навчання, додайте відтворювану команду і `seed`.
3. Укажіть ліцензії й контрольні суми даних; **не завантажуйте** до репозиторію приватні, обмежені або сторонні тексти, яких не маєте права поширювати.
4. Не стверджуйте, що відсотки на синтетичному демо — фактична економія GPT-6/ChatGPT.
5. Зберігайте українську абетку, усі апострофи, Unicode та можливість точного відновлення тексту.

Найпотрібніші задачі: надійний поділ за документами, скрипти bootstrap за документами, незалежні дозволені корпуси, порівняння BPE/Unigram і вимірювання реальної якості LLM після адаптації.
