# UTP v0.7 — двомовна адаптація embeddings у SmolLM2-135M

**Статус:** експериментальний, лише для перевірки інженерної інтеграції. Не є доказом поліпшення мовної моделі, економії в ChatGPT чи результатом незалежного benchmark.

## Гіпотеза

У v0.6 пересаджений словник на 1024 токени суттєво зменшив кількість українських токенів, проте збільшив кількість бітів негативної логарифмічної правдоподібності на байт (тобто погіршив прогнозування тексту). Чотири кроки навчання лише embeddings практично не компенсували втрату. Можливо, більше кроків і двомовне навчання дадуть часткове відновлення обох мов.

## Фіксований експеримент

- Бекбон: HuggingFaceTB/SmolLM2-135M, ревізія `93efa2f097d58c2a74874c7e644dbc9b0cee75a2`, Apache 2.0.
- Корпус: **лише** Tatoeba CC0 українською й англійською, окреме SHA-256 розділення train/test. Жодних текстів UD, ваг із UD чи сторонніх приватних даних.
- Токенізатор: SentencePiece BPE 1024, навчання за пропорцією 75% українських і 25% англійських UTF-8 байтів, з перевіркою round-trip. Початкові вектори відновлюються із pretrained-моделі через наближене проєктування.
- Оптимізатор: AdamW, lr=3e-4, clipping=1.0; навчаються лише таблиці вхідних і вихідних векторів; основний трансформер заморожений.
- Навчальний розклад: **3 українські приклади : 1 англійський**, за заздалегідь визначеним порядком і seed 42. Це кількість навчальних прикладів, **не** частка байтів.
- **Заздалегідь фіксовані** checkpoints: **0, 16, 64, 128** кроків загалом. Зміни між ними — лише додаткові кроки, оптимізатор не скидається.
- Вимірювання: оригінальна мовна модель + її оригінальний токенізатор проти transplanted-моделі на однакових **30 українських та 30 англійських тестових реченнях** (спільний фільтр довжини).
- Метрика: **bits / original UTF-8 byte**, нижче — краще. Порівнювати звичайний perplexity/token між словниками **не можна**. Час CPU на спільному runner — ілюстративний.
- Процедура не обирає найкращий checkpoint за test-результатом; тестування всіх етапів — лише описовий пошук, з ризиком повторного погляду на той самий набір.

## Відтворення

Знадобиться CPU, пам'ять для моделі SmolLM2-135M, Python 3.12.

~~~bash
pip install -r requirements.txt
pip install 'torch==2.6.0' --index-url https://download.pytorch.org/whl/cpu
pip install 'transformers==4.52.4' 'huggingface_hub>=0.30,<1' 'safetensors>=0.4'
python -m pytest -q
python llm_continuation.py --samples 30 --vocab 1024 --seed 42 \
  --out results/llm_continuation_v07.json
~~~

## Обмеження

Тренувальних CC0-речень українською дуже мало; навіть 128 кроків на них — невеликий навчальний обсяг, недостатній для доведення відновлення якості. Вибірка не є незалежною від попередніх експериментів на Tatoeba; джерела можуть містити перефразування. Цей запуск не застосовує LoRA чи повноцінного continued pretraining. Якщо якість не відновиться, висновок: потрібен більший юридично придатний корпус і зміна методу адаптації, а не ще одна декларація «економії токенів».

Будь-які сирі дані та навчені ваги не публікуються. Публікуються лише агреговані числові результати, ревізії та контрольні суми.
