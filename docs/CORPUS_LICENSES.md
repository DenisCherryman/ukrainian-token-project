# Дозволи на українські корпуси (v0.4)

Це попередня матриця джерел. **Ліцензія на оригінальний текст не дорівнює автоматичному дозволу без будь-яких умов публікувати ваги або словник, отримані внаслідок машинного навчання.** Перед релізом потрібна окрема юридична перевірка конкретної збірки.

| Джерело | Ліцензія / умови | Комерційне використання тексту | Потрібно перевірити перед імпортом |
|---|---|---|---|
| UD Ukrainian-IU | CC BY-NC-SA 4.0 | **Ні, за ліцензією без іншого дозволу** | Тільки некомерційне дослідження; дані та моделі з цього корпусу не перевидаємо |
| Tatoeba sentences (CC0 subset) | CC0 1.0 (лише явно позначені CC0 речення) | Зазвичай так | Вибрати саме CC0-експорт, мову Ukrainian, перевірити джерела та якість |
| Tatoeba regular sentences | CC BY 2.0 FR | Так, із зазначенням авторів та умов | Зберігати авторство, відповідність URL/ID та атрибуції; виключити аудіо |
| Ukrainian Wikipedia articles | Здебільшого CC BY-SA 4.0 / GFDL | Так, за умовами ліцензії | Атрибуція, ShareAlike у випадках, коли застосовне; права на вбудовані цитати/медіа |
| UD English-EWT | CC BY-SA 4.0 анотації; джерела тексту можуть мати інші права | **Не визначено для всього джерела** | Ліцензії оригінальних матеріалів окремо |

## Політика імпорту

1. Зберігати лише перевірені першоджерела і точні ліцензійні версії.
2. Розділяти корпуси за типом дозволу: **noncommercial research / attributed reuse / CC0**. Не змішувати їх в артефактах для комерційного випуску.
3. Під час навчання записувати SHA-256, назви/версії джерел, спосіб фільтрації, авторів/атрибуцію там, де необхідно.
4. Не завантажувати сирі сторонні тексти, персональні дані та токенізатори, навчені на обмежених корпусах, до публічного GitHub.
5. Для майбутнього релізу з широким використанням навчити окрему модель на **чистому юридично перевіреному корпусі**, а не перепаковувати поточну навчальну модель з UD.

**Статус:** це дослідницька інвентаризація джерел, не правовий висновок і не остаточно погоджений набір для навчання. Оцінити також приватність та ліцензування похідних артефактів.
